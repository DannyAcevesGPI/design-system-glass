# Fuentes locales

Subset latin de las tres familias del sistema, en WOFF2. La galería y las
previews cargan `fonts.css`; no hacen peticiones a Google Fonts.

| Familia | Archivo | Pesos |
| --- | --- | --- |
| Bricolage Grotesque | `bricolage-grotesque-latin.woff2` | 500–700 (variable) |
| IBM Plex Sans | `ibm-plex-sans-latin.woff2` | 400–600 (variable) |
| IBM Plex Mono | `ibm-plex-mono-latin-400.woff2` | 400 |
| IBM Plex Mono | `ibm-plex-mono-latin-500.woff2` | 500 |

Origen: Google Fonts. Licencias SIL Open Font License 1.1 en los archivos
`OFL-*.txt`. Al redistribuir los archivos, conserva esas licencias.
