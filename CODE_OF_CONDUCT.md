# Código de conducta

## Compromiso

Design System Glass quiere ser un espacio de trabajo respetuoso para personas con cualquier nivel de experiencia, identidad, origen o contexto. Participar aquí implica aceptar este código.

## Comportamiento esperado

- Trata con respeto y empatía a las demás personas.
- Da y recibe crítica constructiva sobre el trabajo, no sobre la persona.
- Reconoce los errores y corrige.
- Explica el contexto de una decisión antes de defenderla.
- Deja espacio para que otras personas pregunten y aprendan.

## Comportamiento inaceptable

- Acoso, amenazas, insultos o ataques personales.
- Comentarios discriminatorios por género, identidad, orientación, discapacidad, etnia, edad, religión o apariencia.
- Atención sexual no solicitada.
- Publicar información privada de otra persona sin permiso.
- Interrumpir de forma reiterada, boicotear o desviar discusiones.
- Usar el proyecto para promocionar productos o servicios sin relación.

## Alcance

Este código aplica a issues, pull requests, discusiones, revisiones y cualquier espacio del proyecto. También aplica cuando alguien representa al proyecto en otro espacio.

## Reporte

Si presencias o sufres una conducta inaceptable, contacta al mantenedor en privado a través de GitHub:

https://github.com/DannyAcevesGPI

Incluye qué pasó, dónde, cuándo y cualquier enlace o captura relevante. Los reportes se revisan con confidencialidad y sin represalias.

## Aplicación

El mantenedor puede pedir una corrección, cerrar una discusión, retirar contenido o bloquear a una persona. La respuesta busca reparar el daño y mantener un espacio seguro, no castigar.
