# Marcas y assets de marca

«Design System Glass», el logotipo y el símbolo del átomo son marcas de **Daniel Aceves**.

La licencia MIT cubre el código, la documentación y los archivos del repositorio, pero **no concede derechos sobre las marcas**. La titularidad de las marcas es independiente de la licencia del software.

## Uso permitido

- Usa el nombre para referirte al proyecto o a una copia no modificada.
- Enlaza al repositorio oficial usando el logo sin modificarlo.
- Menciona el proyecto en documentación, artículos o comparativas sin sugerir patrocinio.

## Uso que requiere permiso

- Usar el nombre o el logo para identificar un fork modificado como si fuera el proyecto oficial.
- Usar las marcas en el nombre de un producto, servicio o evento.
- Sugerir que el proyecto respalda, certifica o patrocina tu producto.
- Alterar el logo y presentarlo como la marca oficial.

## Assets

Los archivos de `assets/brand/` se incluyen para mostrar el proyecto. Puedes copiarlos y modificarlos bajo MIT, pero si creas una versión derivada, usa un nombre y un logo distintos para evitar confusión.

Para pedir permiso de uso de marca, contacta al mantenedor por GitHub:
